# 💻 Portfólio — Ariane Archanjo

Portfólio pessoal com temática **retrô desktop pixelado**, inspirado nas interfaces clássicas do Windows 95/98.

## ✨ Funcionalidades

- **Layout retrô** — janelas, title bars, dots, taskbar e start menu no estilo Windows clássico
- **Background com céu e gramado** — nuvens pixeladas e grama com clip-path
- **Carrossel infinito** — projetos em sliding contínuo com clones e transição seamless
- **Start menu** — navegação completa entre seções escondida no botão "Início"
- **Painel de acessibilidade** — alto contraste, redução de movimento, aumento de fonte
- **Reveal on scroll** — seções aparecem com animação ao rolar a página
- **Cursor pixel art** — setinha customizada no tema do portfólio
- **Responsivo** — adaptado para monitores grandes, tablets e celulares
- **QR Code** — gerado no painel de acessibilidade para compartilhamento rápido

## 📋 Seções

| Seção | Descrição |
|-------|-----------|
| **Hero** | Apresentação com foto, card "about.me" e links |
| **Sobre** | Biografia e valores (acessibilidade, UX) |
| **Skills** | Barras pixeladas de proficiência técnica |
| **Projetos** | Carrossel com projetos em cards estilo janela |
| **Experiência** | Linha do tempo profissional e formação acadêmica |
| **Certificados** | Grid de cursos e certificações |
| **Contato** | Links para LinkedIn, GitHub e e-mail |

## 🛠️ Stack

- **HTML5** — semântico, acessível (WCAG AA)
- **CSS3** — Flexbox, Grid, variáveis, animações, media queries
- **JavaScript** — DOM, IntersectionObserver, carrossel clone-based
- **Font Awesome 6.5.1** — ícones
- **Google Fonts** — Pixelify Sans, Space Mono, VT323
